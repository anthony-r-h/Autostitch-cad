# Demos

One canonical DWG per demo, stored in `examples/demos/`. Rebuilds replace these files; Git keeps the history.

| Demo | Drawing | Contents / status |
| --- | --- | --- |
| Emblem | [emblem.dwg](examples/demos/emblem.dwg) | Centred AUTO Stitch, three concentric circles, 21 landmarks. Guide artwork; fitting still needs adjustment. |
| Quilting | [quilting.dwg](examples/demos/quilting.dwg) | Bolster, Sweep and Fan options. Named views `A-BOLSTER`, `B-SWEEP`, `C-FAN`. Guide artwork; direction not selected. |
| Can You Really | [can-you-really.dwg](examples/demos/can-you-really.dwg) | Selected Velvet lettering and curved background fill. Guide artwork; stitching pending. |

The banner wording remains **Can / You / Really**. [Artwork previews](examples/studies/README.md) show the options.

## Reusable fills

[Fill recipes](docs/FILLS.md) cover diagonal hatch, arc spiral, maze meander, diamond quilt and flowing hatch. Parameters and sample IDs live in `fillRecipes` in [tests/cases.json](tests/cases.json). Quilt A/B reuse diamond quilt; the selected Velvet banner reuses flowing hatch with a text exclusion.

```powershell
./examples/design-studies.ps1 -FillSamples -OutputFolder examples/fills
./tests/check-fill-recipes.ps1
```

Preview and CAD source files are stored in `examples/fills/`, using stable filenames. These samples currently qualify guide generation; stitch fitting is a separate check.

## Reproduce

Run from the repository root. BricsCAD V22 must be open and idle.

```powershell
# Recreate the quilting and lettering SVG, PNG and DXF sources.
./examples/design-studies.ps1

# Build and check DWGs in a new output/native/demo-build-* folder.
./examples/build-demos.ps1

# Build, check, then replace the three canonical DWGs.
./examples/build-demos.ps1 -Publish
```

The emblem is generated by `ASTSHOWCASEARTMORE` in [showcase.lsp](examples/showcase.lsp). The other drawings use the generated DXFs in `examples/studies/`. The build preserves guides and reference boundaries; it does not fit stitches.

Temporary drawings and reports stay under `output/native/`; existing files there may contain user work. Close any canonical demo before publishing a replacement.

The separate [validated stitch specimen](examples/Autostitch-showcase.dwg) remains the regression drawing. Demo artwork is reviewed before it replaces solved examples.
